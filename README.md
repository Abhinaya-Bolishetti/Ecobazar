# 🌱 EcoBazar

EcoBazar is a sustainable e-commerce platform that promotes eco-friendly products and responsible consumption. The platform helps users make environmentally conscious choices by showing the carbon impact of products and enabling smarter purchasing decisions.

---

## 🚀 Project Status
🔧 In Development (Milestone 3 Completed)

---

## 🧩 Tech Stack

### Backend
- Java 17  
- Spring Boot  
- Spring Data JPA  
- Spring Security  
- MySQL  
- JWT Authentication  

### Frontend
- React (Vite)  
- Axios  
- React Router  
- HTML, CSS, JavaScript  

---

## 🔐 Features Implemented

### User Management
- User Registration  
- User Login  
- Encrypted Passwords (BCrypt)  
- Role-based users (USER, SELLER, ADMIN)  

### Product & Catalog
- Add eco-friendly products (Seller)  
- View product catalog (User)  
- Product carbon footprint display  
- Eco-certified product flag  

### Cart & Wishlist
- Add to Cart  
- Remove from Cart  
- Wishlist management  
- Smart cart carbon impact summary  

### Security
- Spring Security integration  
- JWT-based authentication  
- Role-based access control  
- Protected REST endpoints  

---

## 🗂️ Project Structure

- `backend/` – Spring Boot REST API  
- `ecobazaar-frontend/` – React frontend  
- `database/` – MySQL schema (if applicable)  

---

## ⚙️ How to Run Locally

### Backend
```bash
cd backend
mvn spring-boot:run
````

### Frontend

```bash
cd ecobazaar-frontend
npm install
npm run dev
```
